# Awesome-Clinical-Trial-Management-System

# 顶级临床试验管理系统（CTMS）平台生态系统



**精选 SaaS 产品与开源 GitHub 项目列表**

*聚焦研究启动、受试者招募、监测访视、财务与合规管理*

**最后更新：2026 年 9 月**



本仓库追踪 **临床试验管理系统（CTMS）** 领域的知名 **SaaS 平台** 与 **开源项目**。这些工具帮助申办方、CRO 和研究机构管理临床试验的运营活动——从研究启动、受试者招募到监测访视、问题跟踪和财务结算。



**示例** 包括 Medidata Rave CTMS、Veeva Vault CTMS、Oracle Clinical One、Florence Healthcare、Castor、MasterControl、SimpleTrials、RealTime-CTMS、Clinical Conductor 和 Advarra（该领域的领先者）。



**开源重点**：CTMS 的开源生态 **成熟度有限但存在生产级方案**。**Phoenix CTMS** 是最完整的开源选择，将 **CTMS、PRS（受试者招募系统）和 CDMS（临床数据管理系统）** 整合在一个模块化系统中，内置审计追踪，PHI 加密，可在标准 Ubuntu 上部署 。**clinicedc** 是哈佛 T.H. Chan 公共卫生学院和博茨瓦纳-哈佛艾滋病研究所合作开发的 Django 框架，拥有 **119 个模块仓库**，已在 NIH 资助的多项临床试验中用于数据采集、监测和审计 。**OpenClinica** 是全球首个商业开源临床试验软件，社区版免费提供 EDC/CDM 核心功能 。
